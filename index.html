迪加车机巡检消息推送 v1.0.0

这是什么？

基于迪加 2.0（新版API）实现的车机巡检消息推送工具。每分钟自动检测车辆状态变化，通过企业微信群机器人推送消息到手机。

无需电脑、无需编程知识，手机浏览器打开本页面即可完成全部配置部署。

本工具依赖迪加 2.0 系统，感谢迪加作者提供车机API能力，请尊重作者劳动成果。

你需要准备什么？

1. 迪加 2.0 — 车机已安装迪加系统（2.0新版），并开通API访问权限

2. 企业微信群机器人 — 在企业微信群中添加机器人，获取Webhook地址

3. 樱花FRP账号 — 免费内网穿透服务，让车机可被外网访问（1元实名认证）

4. 一部手机 — 用来打开本页面完成配置，全程手机操作

工作原理

迪加自动化任务每分钟触发一次脚本 → 脚本调用迪加2.0 API获取状态 → 检测到变化后通过企业微信机器人推送消息到群。

推送失败时自动进入消息队列，下次巡检时补推，确保消息不丢失。

第四步：部署到车机

1. 复制上一步生成的部署命令
2. 打开微信 → 搜索「迪加服务」小程序 → 进入远程小迪
3. 在「命令内容」输入框中粘贴，点「发送」
4. 等几秒，企业微信群收到「脚本版本」消息即成功

第五步：配置自动化任务（关键！）

脚本部署成功后，还必须配置自动化任务，让脚本每分钟自动执行一次。否则脚本只在手动触发时才跑一次，不会自动巡检推送。
1. 打开迪加 APP → 自动化 → 点右上角「+」新建规则
2. 规则名称：随便取，比如「定时巡检」或「车辆状态监控」（不要跟别人的重名即可）
3. 开关打开
4. 触发条件：添加条件 → 选「分」字段 → 逻辑选「发生变化」（意思是每过一分钟，分从变就会触发）
5. 延迟：0 毫秒，抑制：0 毫秒
6. 满足执行指令：点「+ 指令」 → 选「迪加执行」 → 输入框填入下方生成的命令
7. 否则执行：留空
8. 点右上角保存，规则生效
▲ 参考示例：触发条件选「分」→「发生变化」，满足时执行 SHELL 命令
下方已自动生成自动化任务所需的 SHELL 命令（与部署命令不同，这是每分钟执行巡检的命令），复制后填入第6步的指令输入框。

测试与诊断

部署完成后，建议按顺序逐项测试，确认各功能正常。每项测试都会向企业微信群推送一条结果消息。复制命令后到微信「迪加服务」小程序粘贴发送即可。
① 脚本版本 — 确认脚本已正确写入车机
② API连通 — 测试车机所有API接口（认证码对不对、FRP通不通）
③ 推送通道 — 测试企业微信机器人能否正常推送
④ 锁车诊断 — 测试锁车状态API能否正常读取
⑤ 充电诊断 — 测试充电枪和充电状态API
⑥ 位置诊断 — 测试GPS坐标和高德逆地理编码
⑦ 哨兵诊断 — 测试哨兵事件和视频匹配逻辑
⑧ 胎压诊断 — 测试胎压数据读取和异常判定逻辑
⑨ 查看配置 — 查看当前所有配置项是否正确

配置后修改

部署成功后如需改配置，在微信「迪加服务」小程序 → 远程小迪中执行（均为迪加执行SHELL格式，需编码后发送）。
